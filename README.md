# Karsci Cespedes — Portfolio

A sleek, responsive portfolio for Karsci Cespedes, a Data Science graduate and Business System Analyst based in Cagayan de Oro City, Philippines.

## Highlights

- Dark-violet editorial design with responsive layouts
- Skills, experience, education, certifications, and continuous learning
- Downloadable résumé, portrait, LinkedIn, and email contact
- Accessible navigation and reduced-motion support
- Dedicated social-sharing artwork
- Deployment targets for Sites and Vercel

## Local development

Requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

Run the production checks with:

```bash
npm test
npm run build:vercel
```

The Vercel build exports the server-rendered portfolio as a static site in `.vercel-static`.

## Technology

React 19, TypeScript, Tailwind CSS, vinext, and Vite.
